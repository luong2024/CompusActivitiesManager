1. Tạo model account
• Cấu trúc sử dụng: Class (POCO)
• Chi tiết triển khai: Tạo một lớp C# (ví dụ: Account.cs) chứa các thuộc tính tương ứng với dữ liệu trả về từ API (Id, Username, Email,...) để ánh xạ dữ liệu JSON.
2. Tạo interface cho service (IUserService<T>)
• Cấu trúc sử dụng: Generic Interface (IUserService<T>)
• Chi tiết triển khai: Định nghĩa bộ khung các phương thức bất đồng bộ chung cho các thao tác CRUDL (Create, Read, Update, Delete, List).
3. Tạo AccountService để gọi API
• Cấu trúc sử dụng: Service Class & HttpClient
• Chi tiết triển khai: Tạo lớp AccountService thực thi interface IUserService<Account>, sử dụng HttpClient để gửi các HTTP Request (GET, POST, PUT, DELETE) tới các endpoint /api/accounts.
4. Làm đầy đủ CRUD (lấy danh sách, lấy tài khoản, thêm, sửa, xóa)
• Cấu trúc sử dụng: Async / Await Methods
• Chi tiết triển khai: Triển khai đầy đủ các phương thức bất đồng bộ kết hợp HttpClient (GetFromJsonAsync, PostAsJsonAsync, PutAsJsonAsync, DeleteAsync).
5. Đăng ký Service bằng Dependency Injection
• Cấu trúc sử dụng: Microsoft.Extensions.DependencyInjection (MS.DI)
• Chi tiết triển khai: Cấu hình trong file MauiProgram.cs bằng phương thức AddHttpClient và đăng ký service vào DI Container.
6. Kết nối ViewModel với Service
• Cấu trúc sử dụng: Constructor Injection
• Chi tiết triển khai: Truyền interface IUserService<Account> vào hàm khởi tạo của AccountViewModel để ASP.NET Core DI tự động bơm instance vào.
7. Tạo chức năng load danh sách trong ViewModel
• Cấu trúc sử dụng: ObservableCollection<T>
• Chi tiết triển khai: Khai báo một ObservableCollection<Account> trong ViewModel. Viết phương thức gọi GetAllAsync() rồi thêm các phần tử vào collection để UI tự động cập nhật.
8. Kết nối ViewModel với giao diện
• Cấu trúc sử dụng: Data Binding & BindingContext
• Chi tiết triển khai: Gán instance của ViewModel vào thuộc tính BindingContext của trang XAML (View) ở file code-behind (AccountPage.xaml.cs).
9. Dùng command cho thêm/sửa/xóa sau đó làm các chức năng đó
• Cấu trúc sử dụng: ICommand / RelayCommand
• Chi tiết triển khai: Khai báo các thuộc tính kiểu ICommand (như AddCommand, UpdateCommand, DeleteCommand) gắn trực tiếp vào sự kiện Command của các nút bấm trên giao diện XAML.
10. Lỗi chia thành: Validation error, API error, Network error
• Cấu trúc sử dụng: Try-Catch & HttpRequestException
• Chi tiết triển khai: Bắt ngoại lệ HttpRequestException cho lỗi mạng; kiểm tra response.IsSuccessStatusCode để phát hiện lỗi API và lỗi Validation từ server.
11. Tạo ErrorMessage trong ViewModel
• Cấu trúc sử dụng: Properties & INotifyPropertyChanged
• Chi tiết triển khai: Khai báo biến lưu nội dung lỗi (ErrorMessage) và biến xác định trạng thái có lỗi hay không (HasError), đồng thời kích hoạt thông báo thay đổi giao diện.
12. Hiển thị lỗi giao diện
• Cấu trúc sử dụng: XAML UI Control (Label)
