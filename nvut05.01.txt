BẢNG PHÂN CHIA NHIỆM VỤ KỸ THUẬT (TASK BREAKDOWN)

Kiến trúc & Công nghệ:.NET MAUI (.NET 8) | MVVM Pattern | Dependency Injection | Reactive Extensions / Timers  
Đối tượng áp dụng: Giao diện Quản lý danh sách tài khoản (AC 1.1 - AC 1.4)
GIAI ĐOẠN 1: CẤU TRÚC NỀN TẢNG & KIẾN TRÚC (CORE SETUP)
Task 1.1: Khởi tạo Kiến trúc & Dependency Injection
- [ ] Cấu hình project .NET MAUI (target .NET 8), thiết lập cấu trúc thư mục chuẩn MVVM (`Views/`, `ViewModels/`, `Models/`, `Services/`, `Controls/`).
- [ ] Cài đặt các thư viện NuGet cần thiết:
  - `CommunityToolkit.Mvvm` (Hỗ trợ MVVM source generator, RelayCommand, ObservableProperty).
  - `CommunityToolkit.Maui` (Cung cấp Popup, Converters, Animation).
  - `System.Reactive` hoặc cấu hình `CancellationTokenSource` cho Debounce.
- [ ] Đăng ký View, ViewModel và Services vào container DI trong file `MauiProgram.cs` (`AddTransient`, `AddSingleton`).
Task 1.2: Định nghĩa Model & Data Binding cơ bản
- [ ] Tạo Model `AccountItem` chứa các trường: `Id`, `AvatarUrl`, `FullName`, `UserCode`, `Email`, `Status` (Enum: `Active`, `Reserved`, `Blocked`), `Department`, `Role`.
- [ ] Tạo ViewModel chính `AccountManagementViewModel` kế thừa `ObservableObject`.
GIAI ĐOẠN 2: THỰC HIỆN CÁC ACCEPTANCE CRITERIA (AC)
Task 2.1: AC 1.1 - Hiển thị danh sách thẻ tài khoản (Account Card List)
Phát triển UI (XAML):
  - [ ] Thiết kế `CollectionView` làm danh sách chính.
  - [ ] Xây dựng `DataTemplate` cho thẻ tài khoản (`AccountCardView`):
    - Bọc khung bằng `Border` (cấu hình bo góc `StrokeShape`, shadow hiệu ứng thẻ).
    - Sử dụng `Grid` chia layout: Cột 1 chứa `AvatarView`/`Image` (bo tròn), Cột 2 chứa `Label` (Tên, MSV/Email), Cột 3 chứa Tag trạng thái.
    - Tạo `Border` làm Tag trạng thái và dùng `DataTrigger` / `StyleTrigger` đổi màu nền/màu chữ dựa trên biến `Status` (Ví dụ: Active = Xanh, Blocked = Đỏ).
  - [ ] Thêm menu hành động nhanh: Bọc item trong `SwipeView` (màn hình cảm ứng) hoặc gán `MenuFlyout` / `FlyoutBase.ContextFlyout` (Desktop) với các nút: *Sửa*, *Khóa*, *Xóa*.
Phát triển ViewModel (C#):
  - [ ] Tạo `ObservableCollection<AccountItem> Accounts` để chứa dữ liệu hiển thị.
  - [ ] Viết các `ICommand` xử lý thao tác Swipe/Flyout Menu: `EditAccountCommand`, `ToggleBlockAccountCommand`, `DeleteAccountCommand`.
Task 2.2: AC 1.2 - Tìm kiếm (Search) với Hoãn gõ (Debounce) & Xóa nhanh
Phát triển UI (XAML):
  - [ ] Đặt `SearchBar` ở đầu trang, bind thuộc tính `Text="{Binding SearchQuery, Mode=TwoWay}"`.
  - [ ] Kích hoạt hiển thị nút xóa nhanh mặc định trên `SearchBar`.
Phát triển Logic Debounce (C# - ViewModel):**
  - [ ] Triển khai thuộc tính `SearchQuery`. Khi value thay đổi, kích hoạt cơ chế Debounce:
    - *Cách 1 (Sử dụng `CancellationTokenSource`):* Hủy Token cũ, khởi tạo Token mới và `Task.Delay(400)`, sau đó mới thực hiện hàm gọi API search.
    - *Cách 2 (Sử dụng Rx.NET):* Chuyển đổi sự kiện gõ phím thành `IObservable` và dùng toán tử `.Throttle(TimeSpan.FromMilliseconds(400))`.
  - [ ] Viết hàm `PerformSearchAsync()` để lọc danh sách cục bộ hoặc gọi API tìm kiếm.
Task 2.3: AC 1.3 - Bộ lọc (Filter) qua Chip & Popup
Phát triển Thanh lọc nhanh dạng Chip (XAML & Logic):
  - [ ] Sử dụng `FlexLayout` hoặc `HorizontalStackLayout` bọc danh sách các nút Chip trạng thái (*Tất cả, Đang học, Bảo lưu, Bị khóa*).
  - [ ] Định nghĩa Style cho Chip: Cập nhật màu sắc khi Chip được chọn (`IsSelected`).
  - [ ] Bind sự kiện bấm Chip tới `FilterByStatusCommand(StatusEnum)`.
Phát triển Popup lọc nâng cao (CommunityToolkit.Maui):
  - [ ] Tạo một View mới kế thừa `CommunityToolkit.Maui.Views.Popup` tên là `FilterAccountPopup`.
  - [ ] Đưa các `Picker` hoặc `CollectionView` (`SelectionMode="Multiple"`) vào Popup để chọn nhiều Lớp, Khóa, Quyền.
  - [ ] Tạo nút **"Áp dụng"** và **"Đặt lại"** bên trong Popup.
  - [ ] Trong `AccountManagementViewModel`, viết `OpenFilterPopupCommand` gọi `Shell.Current.ShowPopupAsync(new FilterAccountPopup())` và hứng kết quả lọc trả về để cập nhật danh sách.
Task 2.4: AC 1.4 - Tối ưu UX/UI (Refresh, Infinite Scroll, Responsive)
Cấu hình Pull-to-Refresh:
  - [ ] Bọc `CollectionView` trong một `RefreshView`.
  - [ ] Bind `IsRefreshing="{Binding IsRefreshing}"` và `Command="{Binding RefreshCommand}"`.
  - [ ] Trong `RefreshCommand`: Tải lại trang dữ liệu đầu tiên (Page = 1), xoá danh sách cũ và cập nhật lại `Accounts`.
Cấu hình Cuộn tải thêm (Infinite Scroll / Load More):
  - [ ] Thiết lập thuộc tính cho `CollectionView`: `RemainingItemsThreshold="5"`.
  - [ ] Bind `RemainingItemsThresholdReachedCommand="{Binding LoadMoreAccountsCommand}"`.
  - [ ] Trong `LoadMoreAccountsCommand`: Kiểm tra nếu còn dữ liệu -> tăng Page = Page + 1 -> Gọi API lấy trang tiếp theo -> Append dữ liệu vào `ObservableCollection<AccountItem>`.
Cấu hình Responsive Layout đa thiết bị:
  - [ ] Thiết lập `CollectionView.ItemsLayout` dạng `GridItemsLayout`.
  - [ ] Bind thuộc tính `Span="{Binding GridSpanCount}"` trong ViewModel.
  - [ ] Thêm logic tính toán `GridSpanCount` dựa trên kích thước màn hình:
    - Mobile (Width < 600): Span = 1.
    - Tablet (600 <= Width < 1000): Span = 2.
    - Desktop (Width >= 1000): Span = 3 hoặc 4.
  - [ ] *(Tùy chọn XAML pure)* Sử dụng `OnIdiom` để set tĩnh: Phone = 1, Tablet = 2, Desktop = 3.
